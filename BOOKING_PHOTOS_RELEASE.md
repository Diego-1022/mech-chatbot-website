# Booking images — 10 October 2026

Customers may select up to two optional vehicle images in booking details. The per-file limit is 20 × 1024 × 1024 bytes (displayed as 20 MB). Desktop selection/drag-and-drop and mobile album/rear-camera inputs share the same rules. Image count, size, MIME and binary signatures are checked in both the picker/API. JPG, PNG, WebP, GIF, AVIF and HEIC/HEIF are supported. Browsers without HEIC preview show a fallback and retain original-download support. Original file bytes are stored, not sent to an AI model.

Booking confirmation saves the reservation first, then uploads files sequentially with the reservation's private token. The interface reports the actual attached count. Storage/network failure does not falsely report full image success or create another booking on retry; selected files can be retried from the same confirmation page. After navigation/reload, saved images remain available via the private booking link; unfinished local selections are not persisted across page closure.

Private bytes are held in Cloudflare Workers KV (BOOKING_PHOTOS), with D1 metadata in booking_photos. R2 was not enabled on this account; no R2 checkout or paid-plan upgrade was performed. KV free-plan usage has 1 GB total storage and operation quotas; errors preserve the booking and offer retry. KV edge propagation may delay a newly uploaded image; IMAGE_NOT_READY exposes retry rather than declaring it lost. KV bindings are checked against the generated production configuration before deploy.

The image API requires the matching booking token or signed-in administrator for reads. Only an active booking holder can add files. Metadata omits storage keys/leases; image responses are private/no-store and nosniff. Raw filenames can contain Unicode and are unrelated to English-only booking text fields. Unique (booking_id,slot) prevents a third image; upload leases/nonces prevent parallel retries overwriting completed metadata. Failed transfers clean up their own pending row/key, with best-effort storage cleanup. Expired interrupted leases can be retried after 10 minutes. This is not a content-scanning, antivirus or image-transcoding service.
